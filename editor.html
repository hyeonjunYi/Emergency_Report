내용 입력 → 사진 선택 → 전체 미리보기 → 즉시 GitHub 배포 또는 파일 저장

입력 내용은 이 휴대폰 브라우저에 임시 저장됩니다. 사진은 임시 저장되지 않으므로 자리를 떠나기 전 초안 백업을 저장하세요.

05 · 현장기록사진

사진은 최대 8장. 선택 순서가 보고서 순서입니다. 첫 사진이 상단에 표시됩니다.

선택한 사진은 긴 변 1600px로 줄이고 JPEG로 다시 저장합니다. 위치 등 원본 메타데이터는 포함하지 않습니다.

06 · 게시 전 확인

‘확인 중’ 항목과 보고 기준시각을 검토하고, 사진에 개인정보가 노출되는지 확인하세요. 원본 출동지령서는 게시하지 않습니다.
