# 현장 화재조사 초기 상황보고

계룡소방서 현장대응단 / 작성 기본값: 현장대응단 소방장 이현준

## 처음 GitHub에 올리기

1. ZIP을 압축 해제합니다. ZIP 자체를 저장소에 올리는 방식이 아닙니다.
2. 새 저장소를 만들고 압축을 푼 내용 중 `public` 폴더와 `netlify.toml`, 이 안내문을 저장소 최상위에 올립니다. 기존 날씨/지원출동 저장소와 별도의 저장소 사용을 권장합니다.
3. 결과 구조는 `netlify.toml`, `README.md`, `public/index.html`, `public/editor.html` 등입니다. 폴더를 한 겹 더 감싸지 마세요.
4. Netlify에서 해당 GitHub 저장소를 연결합니다. Base directory는 비움, Build command는 비움, Publish directory는 `public`입니다. Hugo나 npm 설치는 필요 없습니다. 기존 설정에 hugo가 있다면 지웁니다.
5. 배포된 사이트의 첫 화면은 현재 금암동 보고서이고, 주소 뒤에 `/editor.html`을 붙이면 작성 화면입니다. 이 주소를 휴대폰 홈 화면에 추가하세요.

## 현장에서 휴대폰만으로 갱신하기

1. 휴대폰 Chrome 또는 Safari로 배포 사이트의 `/editor.html`을 엽니다. 앱 안의 간이 브라우저 대신 일반 브라우저를 권장합니다.
2. 다음 출동이면 **새 사건 시작**을 누릅니다. 같은 사건 보완이면 사진을 포함한 **초안 불러오기**를 사용합니다.
3. 신고·출동시각, 현장상황, 피해현황을 입력합니다. 작성자는 기본값으로 입력됩니다. 현장에 도착한 조사자의 관점으로 기록하고, 미확인 사항은 확인 중/조사 중으로 남깁니다.
4. 휴대폰 사진을 선택하고 각 설명을 작성합니다. 최대 8장, 첫 사진은 상단 대표사진입니다. ‘앞으로’와 ‘삭제’로 정리합니다. 사진은 1600px JPEG로 재저장합니다. HEIC는 JPEG로 변환 후 선택하세요.
5. **전체 미리보기**로 확인하고, 게시 전 확인란에 체크한 뒤 **게시용 index.html 저장**을 누릅니다. 브라우저에 따라 다운로드/파일 앱에 저장됩니다. 저장이 시작되지 않으면 생성된 ‘index.html 다시 저장’ 링크를 누릅니다. 파일명이 index (1).html 등이면 index.html로 이름을 바꾸세요.
6. GitHub 웹사이트에서 저장소의 **public 폴더**를 엽니다. **Add file → Upload files**에서 저장한 index.html을 선택하고 **Commit changes**를 누릅니다. 모바일에서 메뉴가 숨겨지면 브라우저의 ‘데스크톱 사이트’로 전환합니다. GitHub 앱은 업로드 메뉴가 다를 수 있으므로 웹브라우저를 사용하세요.
7. 연결된 Netlify의 배포가 성공한 뒤 공개 주소를 새로고침합니다. GitHub 업로드 전까지 공개 보고서는 바뀌지 않습니다.

사진·스타일·보고내용이 생성된 index.html 한 파일에 포함됩니다. 매번 사진 폴더를 다시 올릴 필요가 없습니다. public/index.html 교체는 현재 공개 보고서를 바꿉니다. 이전 사건을 별도 주소로 보관하려면 교체 전에 별도 HTML 이름으로 저장하세요. GitHub 기록만으로 별도 공개 사건 목록이 만들어지지는 않습니다.

## 초안 보존과 동작 범위

- 텍스트만 현재 기기의 브라우저에 임시 저장됩니다. 사진은 메모리에만 있으므로 새로고침/종료 시 사라집니다.
- 현장을 떠나기 전 **초안 백업**으로 사진 포함 JSON을 휴대폰에 저장하세요. JSON은 GitHub/public에 올리지 않습니다. ‘초안 불러오기’로 이어 작성합니다.
- 작성화면은 입력 도구입니다. GitHub 쓰기 권한이나 토큰을 포함하지 않으며 누구든 화면은 열 수 있어도 GitHub 권한 없이는 원본 보고서를 바꾸지 못합니다.
- 현재 버전은 입력 내용으로 보고서를 구성합니다. 출동지령서 OCR, 사진을 통한 자동 원인 판단, 버튼 한 번으로 GitHub 직접 게시는 포함하지 않습니다.
- 인터넷으로 작성 화면을 먼저 열어야 합니다. 오프라인 PWA는 아닙니다. 생성된 게시용 HTML은 외부 파일 없이 열 수 있습니다.
- 내보내기는 20MB 이하로 제한합니다. 사진이 많으면 수를 줄여주세요.
- 출동지령서 원본·신고자 전화번호는 포함하지 않았습니다. 공개 전 내용과 사진을 검토하세요. 현재 기기에서 편집하는 초안은 서버로 전송되지 않습니다. GitHub에 올린 파일은 배포 대상입니다.
- 특정 휴대폰의 다운로드/파일선택 화면은 기기마다 다릅니다. 첫 배포 후 실제 사용할 휴대폰에서 사진 선택과 저장을 한 번 확인하세요.

## 파일

- public/index.html: 현재 보고서
- public/editor.html / editor.js / editor.css: 재사용 작성 도구
- public/report.js / style.css: 보고서 생성 코드와 스타일
- public/default.json / assets: 최초 금암동 사건을 다시 불러오기 위한 데이터와 현장사진 4장
- netlify.toml: 빌드 없이 public 배포

## 화면 스타일

사용자가 제공한 디자인 기준에 맞춰 정부 블루·네이비, 17px 본문, 최대12px 모서리, 2px 포커스, 48px 버튼과 선명한 화면 모드를 적용했습니다. 시스템에 설치된 한글 글꼴을 사용하며 외부 폰트 다운로드는 없습니다. 사진은 수동 전환합니다. 공식 전자정부 인증 배너나 정부 상징을 추가하지 않았습니다. 이 구성만으로 접근성 인증이나 완전 준수를 주장하지 않습니다.
